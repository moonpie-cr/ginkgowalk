# 🍂 银杏大道 · 十二个月的记忆

一个第一人称 3D 互动网页。沿着一条金黄的银杏大道慢慢往前走，脚下的落叶会被踩起来，耳边是沙沙声和风声。路边立着 12 块「记忆路牌」，每块对应一年中的一个月，走到跟前会停下，弹出这个月的记忆卡片，还可以听一段当月的旋律。走到大道尽头，漫天落叶会聚成四个字：**渐入佳境**。

整个作品只有一个文件：`ginkgo-walk.html`。

---

## ✨ 主要特点

- **银杏大道场景**：傍晚的逆光、远处的雾、成排的银杏树、路灯和长椅，全程约 390 米。
- **会被踩散的落叶**：地上铺着几千片银杏叶形状的落叶，走过时会被踢起、在空中翻转后再落回地面；树上也一直有叶子飘下来。
- **实时合成的声音**：脚步沙沙声、风声、到达路牌时的提示音，以及 12 首当月旋律，都是网页实时合成的，不需要任何音频文件。
- **自动漫步**：打开就会自己往前走，到路牌自动停下，不需要会玩游戏也能看完。
- **十二张记忆卡片**：一月到十二月，每张卡片有专属配色的插画、标题、日期和一段短句。
- **落叶粒子结尾**：走到终点，金色叶片从四周飘来，组成「渐入佳境」。
- **电脑、手机都能用**：手机上会自动减少落叶和树木数量，保证流畅。

---

## 🚀 怎么打开

1. 用浏览器打开 `ginkgo-walk.html`（推荐 Chrome、Edge 或 Safari 的较新版本）。
2. 点 **「开始漫步」**。
3. 戴上耳机效果更好。

> ⚠️ **需要联网**：网页的 3D 部分会从网上加载 Three.js（0.160.0 版本）。没有网络时画面无法显示。

## 🎮 操作说明

### 自动漫步（默认）

| 情况 | 会发生什么 |
|---|---|
| 点「开始漫步」后 | 自动沿大道往前走 |
| 到达路牌 | 停下，镜头转向路牌，弹出这个月的卡片 |
| 点 **▶** 或按 **M** | 播放当月旋律；播放时不会自动往前走 |
| 点 **继续漫步 →**，或按 **空格 / 回车** | 马上走向下一块路牌 |
| 什么都不做 | 12 秒后自动继续（卡片上有倒计时） |
| 走完 12 块路牌 | 按钮变成「走向尽头 →」，终点出现「渐入佳境」 |

### 手动行走

| | 电脑 | 手机 |
|---|---|---|
| 走路 | W A S D 或方向键 | 左半边屏幕拖动 |
| 环顾四周 | 点一下画面后移动鼠标 | 右半边屏幕拖动 |
| 小跑 | 按住 Shift | 摇杆推到底 |
| 听当月旋律 | M，或点卡片上的 ▶ | 点卡片上的 ▶ |
| 释放鼠标 | Tab 或 Esc | — |

- 按方向键（或在手机上拖动摇杆）会**立刻切换为手动**，走近路牌时卡片会自动弹出，走开后收起。
- 点左上角的 **🚶** 可以切回自动，它会从当前位置接着走向下一块路牌。
- 左上角的 **🔊** 可以开关所有声音。

## ✏️ 想改内容？

用任意文本编辑器（如 VS Code、记事本）打开 `ginkgo-walk.html`，搜索下面的关键词即可修改。改完保存，刷新网页就能看到。

### 改卡片文字：搜索 `const MONTHS`

每个月是一行，例如：

```js
{ title:'十月 · 银杏', date:'2026.10', emoji:'🍂', sky:['#f0c058','#fbe7b0'],
  text:'就是这条路。\n踩着落叶走了很久，沙沙声像在说话。' },
```

| 字段 | 含义 |
|---|---|
| `title` | 卡片和路牌上的标题 |
| `date` | 日期 |
| `emoji` | 卡片插画中间的图案 |
| `sky` | 卡片插画的渐变色（上、下两个颜色） |
| `text` | 卡片上的一段话，`\n` 表示换行 |

### 改结尾文字：搜索 `渐入佳境`

- 落叶拼出的大字在 `makeFinaleTargets` 里的 `g.fillText('渐入佳境', ...)`。
- 底部的小字说明在 HTML 的 `id="finaleCaption"` 里。
- 文字建议 2～6 个字，太长会显得拥挤。

### 其他常用参数

| 搜索 | 作用 | 当前值 |
|---|---|---|
| `const WAIT_SEC` | 自动漫步时，每块路牌停留的秒数 | 12 |
| `const NG` | 地面落叶数量（手机 / 电脑） | 3400 / 8200 |
| `const NF` | 空中飘落的叶子数量（手机 / 电脑） | 260 / 650 |
| `const SONGS` | 12 首旋律的曲谱、速度和音色 | — |

> 如果电脑上觉得卡，可以把 `NG`、`NF` 后面的数字调小。

## 🛠 技术说明

- 单个 HTML 文件，无需安装、无需构建。
- 3D 渲染：[Three.js](https://threejs.org/) 0.160.0，通过 CDN 引入。
- 落叶使用 InstancedMesh 批量绘制；声音全部使用 Web Audio API 实时合成。
- 卡片插画使用 Canvas 实时绘制，不依赖任何外部图片。
- 界面支持浅色 / 深色模式。

## ❓ 常见问题

**打开后一片空白？**  
检查网络是否正常，Three.js 需要从网上加载。也可以换用较新版本的 Chrome 或 Edge 再试。

**没有声音？**  
浏览器要求先有一次点击才能播放声音，点「开始漫步」后就会有声音。也请检查左上角是否为 🔊，以及设备是否静音。

**手机上转视角不灵敏？**  
用右半边屏幕拖动转视角，左半边拖动是走路。

**鼠标被锁住了？**  
按 Esc 或 Tab 即可释放。
